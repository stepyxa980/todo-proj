# Task Manager

Простой консольный менеджер задач с сохранением состояния в JSON-файл.

## Основные возможности

- 📝 Добавление новых задач с автоматической фиксацией времени создания
- ✔️ Отметка задач как выполненных
- ❌ Удаление задач
- 📋 Просмотр списка всех задач
- 💾 Автоматическое сохранение состояния в файл `data.json`
- 🔄 Автозагрузка задач при запуске приложения

## Требования

- Python 3.6 или новее

## Установка

1. Клонируйте репозиторий:
```bash
git clone https://github.com/your-username/task-manager.git
cd task-manager
```

2. Запустите приложение:
```bash
python task_manager.py
```

## Использование

После запуска программы используйте следующие команды:

| Команда | Действие                          |
|---------|-----------------------------------|
| 0       | Выход из программы                |
| 1       | Добавить новую задачу             |
| 2       | Удалить задачу                    |
| 3       | Отметить задачу как выполненную   |
| 4       | Просмотреть список задач          |
| 5       | Сохранить задачи в файл           |

### Особенности интерфейса
- Задачи нумеруются начиная с 1
- Статус задачи отображается символами:
  - `@` - задача выполнена
  - ` ` - задача не выполнена
- Время создания задачи фиксируется автоматически
- Данные автоматически сохраняются при выходе

## Формат хранения данных
Все задачи сохраняются в файл `data.json` в следующем формате:
```json
[
    {
        "time": "2023-07-15 14:30:00",
        "description": "Пример задачи",
        "done": false
    }
]
```
